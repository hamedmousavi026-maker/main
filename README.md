# هم‌زبان

بازسازی فرانت‌اند آزمایشی «هم‌زبان» (مترجم همراه شما) با همان سبک نئومورفیسم، پالت سبز و خاکستری آبی، فونت Vazirmatn و چیدمان راست‌به‌چپ.

این نسخه سه محیط دارد:

- **مسافر:** رزرو مترجم با انتخاب شهر، هدف سفر، زبان‌ها، زمان، مدت و محل ملاقات روی نقشه. مشاهده و لغو نوبت‌ها.
- **مترجم:** آنلاین/آفلاین شدن، پذیرش یا رد درخواست‌ها، پیشرفت وضعیت نوبت‌های فعال و نقشه‌ی نوبت‌ها.
- **مدیریت:** آمار کلی، تأیید یا تعلیق مترجمان و فیلتر نوبت‌ها بر اساس وضعیت.

داده‌ها نمونه (mock) هستند و در `localStorage` مرورگر ذخیره می‌شوند. دکمه‌ی «بازنشانی داده‌ها» در هدر آن‌ها را به حالت اولیه برمی‌گرداند. بک‌اند واقعی وجود ندارد.

## اجرا

```bash
npm install
npm run dev      # توسعه، روی 0.0.0.0:5173
npm run build    # ساخت نسخه‌ی تولید در dist/
npm run preview  # پیش‌نمایش نسخه‌ی ساخته‌شده
```

## ساختار

```
src/
  main.jsx          نقطه‌ی ورود
  App.jsx           هدر، انتخاب نقش و محل نمایش هر محیط
  store.jsx         وضعیت سراسری (reducer + localStorage)
  data.js           شهرها، زبان‌ها، مترجمان نمونه، وضعیت‌ها
  utils.js          ارقام فارسی، قالب مبلغ و زمان
  styles.css        توکن‌های طراحی و استایل‌ها
  components/Map.jsx  نقشه‌ی Leaflet با کاشی OpenStreetMap
  views/Passenger.jsx
  views/Translator.jsx
  views/Admin.jsx
```
