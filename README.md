# هم‌زبان (نسخه‌ی آزمایشی v2.4)

پروژه‌ی اصلی به صورت یک فایل HTML بسته‌بندی‌شده بود. حالا در این مخزن:

- `src/app.js` کد کامل برنامه است (از بسته‌ی اصلی استخراج شده و قالب‌بندی شده).
- `src/styles.css` استایل‌های اصلی است (نئومورفیسم، پالت سبز و خاکستری آبی، فونت Vazirmatn).
- `index.html` همان قالب اصلی است که به این فایل‌ها وصل شده.
- `reference/hamzaban-original.html` فایل اصلی بدون تغییر است.

## اجرا

```bash
npm install
npm run dev      # توسعه روی 0.0.0.0:5173
npm run build    # خروجی یک فایل مستقل در dist/index.html
```

## یادداشت

- کد استخراج‌شده کد کامپایل‌شده‌ی React است (نام متغیرها کوتاه‌اند)، نه JSX اصلی. ادامه‌ی توسعه روی همین کد انجام می‌شود.
- کتابخانه‌های React، React DOM، Leaflet و lucide-react داخل همین کد باندل شده‌اند، پس نیازی به نصب جداگانه نیست.
- ترجمه گفت‌وگو است؛ مشاوره‌ی حقوقی، وکالت یا ترجمه‌ی رسمی نیست.
